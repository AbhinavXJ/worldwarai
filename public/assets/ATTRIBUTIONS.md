# Asset attributions

AI MASCOT BATTLE is an **unofficial, non-commercial fan parody**. It is not affiliated with,
endorsed by, or sponsored by OpenAI, Meta or xAI.

All files are stored locally under `public/assets/`. Nothing is fetched from an external URL
at runtime.

## Third-party brand assets

These belong to their owners. They are included only so the parody mascots look like the real
ones. They are **not** covered by this project's license. Delete them (see "Removing brand
assets" below) before any commercial use, and check each owner's brand guidelines before
deploying publicly.

### Removing brand assets

The game keeps working without them:

- Delete `dots/*.glb` and every Dot becomes a procedural felt blob (`buildDotFallback`).
- Delete `dots/posters/`, `muse/` and `grok/` and edit `components/game/MascotIcon.tsx` to drop
  the icons.
- To fully de-brand the Grok Bots and Jolly, replace `lib/game/grokMark.ts` and `buildMuse` with
  original shapes.

## Everything else is generated by the game

| What | How it's made | Where |
| --- | --- | --- |
| Fur / felt shading for Dots and Muses | Shader injection + stacked shell geometry | `lib/game/fur.ts` |
| NPCs, the CEO, the paperclip assistant | Procedural three.js geometry | `lib/game/events.ts`, `lib/game/secrets.ts` |
| Islands, city, trees, rocks, portals, launch pads, billboards, moon | Procedural geometry + canvas-drawn textures | `lib/game/world.ts`, `lib/game/textures.ts` |
| Hallucinated props (banana, toaster, rubber duck, computer, keyboard, emoji) | Procedural geometry | `lib/game/props.ts` |
| Particles, text pops, speech bubbles | Canvas textures + GPU point/instanced shaders | `lib/game/particles.ts`, `lib/game/textures.ts` |
| Sound effects and music | WebAudio synthesis, no sample files | `lib/game/audio.ts` |
| Share card | Canvas 2D, drawn locally in the browser | `lib/game/share.ts` |

## Adding assets

Put new files in a matching folder under `public/assets/` and add a row here with the source
URL, author and license (prefer CC0).
